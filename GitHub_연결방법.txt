빅캣 세미나 사이트 — GitHub 자동 배포 + 관리자 페이지 연결 방법
================================================================

한 번만 설정하면, 그다음부터는
  관리자 페이지(사이트주소/admin.html)에서 파일 올리기·카드 수정 → [저장]
  → GitHub에 자동 저장 → Netlify가 1~2분 뒤 사이트 자동 갱신
이 됩니다. 폴더를 다시 끌어다 놓을 필요가 없어요.


1단계. GitHub 저장소 만들기 (5분)
------------------------------------
1) github.com 로그인 → 오른쪽 위 [+] → New repository
2) Repository name: bigcat-seminar  (원하는 이름)
3) Private(비공개) 선택 가능 → [Create repository]


2단계. 배포용 폴더를 GitHub에 처음 올리기 (GitHub Desktop 추천)
------------------------------------------------------------------
※ 파일이 1,200개·약 700MB라서 웹 화면 업로드(한 번에 100개 제한)보다 GitHub Desktop이 편해요.
1) desktop.github.com 에서 GitHub Desktop 설치 → 로그인
2) File → Clone repository → bigcat-seminar 선택 → 내 PC에 빈 폴더가 생김
3) '배포용_빅캣세미나' 폴더 "안의 내용 전부"를 그 빈 폴더로 복사
   (index.html, admin.html, data.js, data.json, app, web_thumbs, 층별 폴더들)
4) GitHub Desktop 왼쪽 아래 Summary에 "처음 올리기" 입력 → [Commit to main] → [Push origin]
   (용량이 커서 몇 분 걸려요)


3단계. Netlify를 GitHub에 연결
--------------------------------
기존 사이트(cheerful-empanada)를 그대로 쓰려면:
  Netlify → 사이트 선택 → Site configuration → Build & deploy → Continuous deployment
  → [Link repository] → GitHub → bigcat-seminar 선택
  → Build command: 비워두기 / Publish directory: 비워두기(또는 /) → [Deploy]
새 사이트로 하려면: Netlify → Add new site → Import an existing project → GitHub → 같은 설정


4단계. 관리자용 토큰 만들기
------------------------------
1) GitHub → 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings
2) Personal access tokens → Fine-grained tokens → [Generate new token]
3) Token name: bigcat-admin / Expiration: 원하는 기간
4) Repository access: Only select repositories → bigcat-seminar
5) Permissions → Repository permissions → Contents: Read and write
6) [Generate token] → github_pat_… 로 시작하는 값을 복사 (다시 볼 수 없으니 메모)


5단계. 관리자 페이지 쓰기
---------------------------
1) 사이트주소/admin.html 열기  (예: https://cheerful-empanada-fecb55.netlify.app/admin.html)
2) [⚙ GitHub 설정] → 저장소 주인(내 GitHub 아이디), 저장소 이름, 브랜치(main), 토큰 입력
3) 왼쪽에서 카드 선택 → 파일 끌어다 놓기 / 설명·비고·링크 수정 / [＋]로 새 카드
4) [💾 저장 → GitHub 반영] → 1~2분 뒤 사이트에 반영

· 이미지는 자동으로 JPG(긴 변 2000px)로 줄이고 미리보기 이미지도 함께 올려요.
· 음원·PDF는 원본 그대로 올려요 (파일 하나 95MB까지).
· ‘빼기’·‘카드 삭제’는 목록에서만 빠지고 파일은 저장소에 남아요.
· 토큰은 그 브라우저에만 저장돼요. 공용 PC에서는 쓰지 말고, 다 쓰면 [연결 해제]를 누르세요.
· admin.html 주소를 남이 알아도 토큰 없이는 아무것도 바꿀 수 없어요.

주의 — 앞으로는 GitHub가 '원본'이에요
  관리자 페이지로 고친 내용은 GitHub에만 있어요.
  PC 폴더에서 Claude에게 "배포용 갱신해줘"를 하면 PC 폴더 기준으로 다시 만들어지니,
  그때는 GitHub의 data.json을 먼저 받아서 합치도록 말해 주세요.
