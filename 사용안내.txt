BIGCAT ACADEMY — 서버 없는 폴더형 자료실

[자료 보기]
1. ZIP 파일을 먼저 모두 압축 해제합니다.
2. BIGCAT_OFFLINE 폴더의 index.html을 Chrome 또는 Edge로 엽니다.
3. 층과 교구를 선택해 이미지, 음악, PDF를 확인하고 다운로드합니다.
4. 인터넷 없이 작동합니다. 유튜브 등 외부 웹 링크는 인터넷이 필요합니다.

[자료 편집과 배포]
1. 오른쪽 위 '자료 편집'을 누릅니다.
2. '현재 자료 폴더 선택'에서 index.html이 있는 BIGCAT_OFFLINE 폴더를 선택합니다.
   브라우저의 폴더 선택 안내를 허용하세요. 파일은 이 컴퓨터에서만 읽으며 서버로 보내지 않습니다.
3. 각 교구를 눌러 이미지·음악·PDF를 추가하고, 링크 이름과 주소 또는 비고를 입력합니다.
4. '배포 ZIP 저장'을 누르고 다운로드가 끝났는지 확인합니다.
5. 새 ZIP을 압축 해제해 내용을 확인하고, ZIP 또는 폴더 전체를 전달합니다.

편집은 기존 디스크 파일을 직접 수정하지 않습니다. 새 ZIP을 저장해야 변경 내용이 보존됩니다.
창을 닫거나 새로고침하면 ZIP에 저장하지 않은 편집 내용은 사라집니다.
단순히 assets 폴더에 파일을 복사하는 것만으로는 교구에 등록되지 않습니다.
반드시 앱의 파일 추가 기능으로 등록한 후 ZIP을 저장하세요.
재편집은 새 ZIP을 푼 폴더에서 같은 순서로 진행하세요.

[파일 구성]
index.html : 실행 파일
app.js / style.css : 앱 기능과 디자인
 data.js : 층별 목록, 비고, 링크, 자료 경로
assets/ : 이미지·음악·PDF 및 안내 포스터

index.html만 보내면 자료가 누락됩니다. 폴더 전체 또는 ZIP을 전달하세요.
파일명과 폴더 구조를 임의로 변경하면 링크가 끊어질 수 있습니다.
현재 안내 포스터 4장과 활동 42개가 포함되어 있습니다. 개별 교구 자료와 음악은 추가해 주세요.

[호환성]
편집·폴더 선택·ZIP 저장은 PC 또는 Mac의 최신 Chrome/Edge 사용을 권장합니다.
아이폰/iPad의 파일 앱 미리보기는 HTML 스크립트나 음악 재생을 제한할 수 있습니다.
모바일 실행 지원은 OS/브라우저별로 다르며, PC 브라우저 실행을 기준으로 제작했습니다.
음악 재생 가능 형식은 브라우저에 따라 다릅니다. MP3 권장.
파일당 50MB 제한. 큰 자료는 여러 ZIP으로 나누는 것이 좋습니다.
로그인·서버·설치·외부 CDN이 필요하지 않습니다.
편집 화면은 보안 잠금 기능이 아닙니다. 파일을 받은 사람은 자신의 복사본을 수정할 수 있습니다.
